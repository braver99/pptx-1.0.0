① WiFi-CSI 是什么

CSI（Channel State Information，信道状态信息） 描述无线信号从发射端到接收端时，在每个子载波上的幅度和相位变化。它比只给一个平均功率值的 RSSI 精细得多——802.11n 的 20 MHz 信道通常拆成几十到上百个子载波。

人员存在检测原理：人体会吸收、反射、散射 WiFi 信号。当有人进入监测区域时，CSI 的幅度和相位分布会发生明显变化——有人时 CSI 波动（方差、动态分量能量）显著大于无人时的静态环境。通过分析 CSI 幅度的统计特征，就能判断区域内是否有人。

为什么适合做毕业设计 这是 CSI 感知里最简单、最入门的方向——本质是一个「有人 / 无人」的二分类问题，无需复杂算法，ESP32 官方框架自带此示例，非常适合低成本、短周期的本科毕业设计。

② 它能做什么（应用场景）

场景说明
智能家居 本课题有人自动开灯 / 空调，无人自动关闭
安防入侵检测检测是否有人非法进入房间
独居老人监护长时间无人活动 → 告警（跌倒 / 意外）
会议室 / 教室占用检测判断房间是否被占用
节能管理无人自动断电、关闭设备

人员存在检测也是毫米波雷达人体存在传感器（小米、Aqara 等）正在做的商用场景，但 WiFi CSI 方案无需额外硬件、成本更低。

③ 检测方法（三类，从易到难）

方法思路实现难度特点
统计阈值法 最推荐算 CSI 幅度的方差 / 动态分量能量，超过阈值判定「有人」★ 最简单无需训练、实时快，但阈值需人工调
机器学习分类提取统计特征（方差、相关系数、峰度等），SVM / 随机森林 / KNN 二分类★★ 中等精度更高、更稳健，需少量标注数据
深度学习CSI 幅度矩阵输入 CNN / LSTM，端到端二分类★★★ 进阶精度最好，但需更多数据与算力

本科毕业设计建议：先做「统计阈值法」跑通，再加 SVM / 随机森林对比——既保证工作量，又容易出结果。

⑤ 算法流程（毕业设计的核心工作量）

  1. 数据采集 —— 用 ESP32 / Intel 5300 持续采集 CSI 幅度时间序列
  2. 预处理 —— Hampel 去异常值、滑动平均平滑、可选相位校准
  3. 特征提取 —— 计算滑动窗口内的统计特征：方差 / 标准差 / 相关系数 / 动态分量能量
  4. 判决 —— 统计阈值法（特征 > 阈值 → 有人）或分类器（SVM / 随机森林）输出「有人 / 无人」
  5. 输出与联动 —— 实时显示状态，可联动继电器 / 灯 / 蜂鸣器

核心点：有人时 CSI 幅度的方差显著增大，这是最直观、最好用的判别特征。

⑥ 实验设计（答辩最有说服力的部分）

  • 有人 vs 无人 检测准确率（混淆矩阵）
  • 不同距离（1m / 3m / 5m / 7m）
  • 非视距（隔墙 / 隔门）场景
  • 静止的人 vs 走动的人
  • 不同阈值 / 不同分类器对比（阈值法 vs SVM vs 随机森林）
  • 不同子载波 / 不同天线数量

评价指标：检测准确率、误报率、漏报率、混淆矩阵、ROC 曲线。

⑨ 落地建议（给大四低成本）

结论：这是三个方向里最容易实现、最容易落地的一个

落地层次可行性说明
A. 毕业设计 Demo✅ 完全可行一块 ESP32 + 网页 / 手机显示「有人 / 无人」状态，联动一个 LED / 继电器
B. 校园场景小应用✅ 较可行宿舍 / 教室占用检测、节能开关，单人 / 少人场景稳定
C. 商用级产品⚠️ 部分可行智能家居人体存在检测是成熟市场，但 WiFi 方案在多人、动态场景需更精细处理
建议定位 Demo 形态：ESP32 采 CSI → UDP 发电脑 → Python 算方差 / 分类 → 网页实时显示「有人 / 无人」+ CSI 波形，联动 LED。这个 Demo 答辩时直观、可现场演示、工作量合适。

时间节奏（1~3 个月，比定位 / 呼吸更短）：环境搭建 1 周 → 跑通 esp-csi human detection 示例 1 周 → 自己采集 + 分类器调参 1~2 周 → 实验 + 写论文 3~4 周。
