① WiFi-CSI 是什么

CSI（Channel State Information，信道状态信息） 描述无线信号从发射端到接收端时，在每个子载波上的幅度和相位变化。它比传统只给一个平均功率值的 RSSI 精细得多 —— 802.11n 的 20 MHz 信道通常拆分成几十到上百个子载波，每个子载波都是一个复数（幅度 + 相位）。

核心原理：人体呼吸会引起胸腔 / 腹腔 几毫米级的周期性起伏，这会改变 WiFi 多径传播路径，从而在 CSI 上留下周期性的微弱波动。人的呼吸频率约为 0.1 ~ 0.5 Hz（6 ~ 30 次/分钟），对 CSI 时间序列做频域分析，峰值频率就是呼吸频率。

为什么值得做 无需穿戴设备 · 不侵犯隐私（不像摄像头）· 利用现有 WiFi 设备 · 成本极低 · 研究方向成熟、资料充分，非常适合本科毕业设计。

② 它能做什么（应用范围）

类别典型应用
生命体征监测 本课题呼吸率、心率、睡眠监测、呼吸暂停（睡眠呼吸障碍）预筛查
人体活动识别走路 / 跑步 / 跌倒检测、手势识别、按键识别
室内定位与感知人员存在检测、人数统计、步态分析、身份识别
其他情绪识别、目标成像、姿态估计

对毕业设计而言，呼吸频率检测是其中入门最友好、数据最易获取、评价指标最明确的子方向。

③ 技术路线（做完的完整路径）

  1. 数据采集 —— 用 ESP32 / Intel 5300 提取 CSI 子载波幅度与相位时间序列
  2. 相位校准 —— 消除载波频率偏移（CFO）与采样频率偏移（SFO）带来的相位失真（常用共轭相乘 / CSI 比值模型）
  3. 去异常值 —— Hampel 滤波（中位数 + MAD，抗噪强）
  4. 滤波 —— 呼吸频带 0.1 ~ 0.5 Hz 带通滤波（滤除高频噪声与低频身体运动伪影）
  5. 子载波选择 / 降维 —— 挑呼吸频带内信噪比最高的子载波，或用 PCA 主成分分析提取主成分
  6. 信号分解（可选） —— VMD / EMD / 希尔伯特-黄变换（HHT），去除呼吸以外的模态，提升精度
  7. 频率估计 —— FFT 找峰值频率，或峰值检测 + 呼吸计数 + 卡尔曼滤波融合

⑤ 算法流程（毕业设计的核心工作量）

#步骤常用方法
1数据采集得到子载波幅度 / 相位时间序列
2相位校准共轭相乘（SpotFi 核心步骤）、CSI 比值模型
3去异常值Hampel 滤波（中位数 + MAD）
4滤波0.1 ~ 0.5 Hz 带通滤波
5子载波选择按呼吸信噪比（BNR）选最优子载波，或 PCA 降维
6信号分解（可选）VMD / EMD / HHT
7频率估计FFT 峰值检测；峰值检测 + 呼吸计数 + 卡尔曼滤波

最经典的 「PCA + FFT」基线工作量适中、好复现；想做出亮点可再加 VMD 或机器学习。

⑥ 实验设计（答辩最有说服力的部分）

  • 不同呼吸频率下的检测精度
  • 人体不同朝向（面对 / 侧对 / 背对收发设备）
  • 不同距离（1m / 3m / 5m / 7m…）
  • 非视距（隔墙）场景
  • 有无身体动作干扰
  • （进阶）双人呼吸分离

参考真值（Ground Truth）：用呼吸传感器（如 HKH-11C，几十元）同步记录实际呼吸，计算 MAE / 均方误差 / 准确率。

⑩ 落地建议（给大四低成本）

结论：能实现，且能做成「可演示、可答辩」的完整系统

落地层次可行性说明
A. 毕业设计 Demo✅ 完全可行一块 ESP32 + 显示器 / 网页实时显示呼吸波形和频率，答辩演示效果很好
B. 校园场景小应用⚠️ 半可行单人静止场景 OK；多人、多动场景精度会下降
C. 商用医疗级产品❌ 基本不可行精度 / 鲁棒性达不到医疗器械标准，全球几乎没有成功的纯 WiFi 呼吸监测商品
建议定位 把「落地」定位在 A 层（可演示 Demo）+ 少量 B 层展望，这已是满分水平。不要抱着「做出能卖的产品」的预期，否则会耗费大量时间在商用级鲁棒性上。

时间节奏（2~4 个月）：环境搭建 1~2 周 → 跑通基线 1~2 周 → 自己采集调参 2~3 周 → 实验 + 写论文 4~6 周。
