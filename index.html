① WiFi-CSI 是什么

CSI（Channel State Information，信道状态信息） 描述无线信号从发射端到接收端时，在每个子载波上的幅度和相位变化。相比只给一个平均功率值的 RSSI，CSI 保留了信号的相位、到达角（AoA）、传播时延（ToF）和多普勒等精细信息。

定位原理：信号经过不同路径到达接收端，每条路径的到达角、时延、衰减都不相同。CSI 记录了这些多径信息，因此可以从 CSI 中反推出目标位置——要么用"指纹"（不同位置的 CSI 特征不同），要么用"几何"（AoA / ToF 反解坐标）。

为什么值得做 GPS 在室内失效，而 WiFi 无处不在；CSI 定位无需额外设备、成本低、精度可达米级甚至分米级，是室内定位与感知领域最热门的研究方向之一。

② 它能做什么（应用范围）

类别典型应用
静态定位 本课题指纹定位：人在房间 / 楼层的哪个位置
轨迹追踪连续定位、行人轨迹绘制
无源（被动）定位目标不携带设备也能被定位（device-free）
室内导航与感知商场导览、资产追踪、人员存在检测、人数统计
与活动识别联合同时识别"人在哪 + 在做什么"

对毕业设计而言，「CSI 指纹定位」是入门最友好、实验最可控、评价指标最明确的子方向；想进阶可做AoA / ToF 几何定位或深度学习指纹。

③ 定位方法（三大类）

方法原理代表系统 / 算法特点
指纹法
Fingerprinting		离线采集各位置 CSI 特征建指纹库，在线匹配定位kNN、WKNN、SVR、CNN、LSTM精度稳、无需几何模型，但建库耗时、环境变化需重建
几何法
Geometric		用 AoA / ToF / 距离模型反解坐标SpotFi（AoA）、Chronos（ToF）、MUSIC 算法无需离线建库，但需精确校准、受多径影响大
融合法
Hybrid		多维参数（AoA + ToF + DFS）联合定位多维参数融合、深度学习端到端精度高，但系统复杂度高

本科毕业设计最稳妥的路线：「CSI 幅度/相位指纹 + WKNN/SVR 或 CNN」，工作量适中、易出结果；进阶可尝试 SpotFi 的 AoA 几何定位。

④ 硬件采集方案

方案硬件成本特点
经典科研路线Intel 5300 网卡 + Linux CSI Tool（两台笔记本）二手卡约 ¥100数据最标准、中文论文几乎都用它
低成本路线（推荐）ESP32-S3 / ESP32-C3 开发板 + 路由器¥50 ~ 300ESPARGOS / esp-ppb 已支持 MUSIC AoA 与 ToF 定位
手机路线Nexus 5（改驱动）等需特定机型武汉大学等自研手机 CSI 采集工具
SDR 路线USRP N210 + GNU Radio较贵学术研究用，数据最灵活
⚠ 关键决策 定位需要多个 AP / 锚点（指纹法通常 2~4 个）。若走 Intel 5300 路线需 2 台以上设备；走 ESP32 路线可用多块开发板组网，成本更低、更适合低成本毕业设计。

⑤ 算法流程

指纹定位（推荐，两阶段）

阶段步骤常用方法
离线训练数据采集在各参考点采集 CSI，记录真实坐标
预处理Hampel 去异常、相位校准（共轭乘法 / 线性拟合）、小波去噪
特征提取幅度 / 相位 / 特征图像 / PCA 降维
建指纹库特征 + 坐标 存入数据库
在线定位匹配kNN / WKNN / 马氏距离 WKNN / SVR / CNN / LSTM
输出坐标估计位置 + 定位误差

几何定位（进阶，AoA / ToF）

  1. 多天线 / 多 AP 采集 CSI
  2. 用 MUSIC / ESPRIT 超分辨算法估计各径到达角（AoA）
  3. 或从相位差估计传播时延（ToF）
  4. 多 AP 三角定位反解坐标（SpotFi / Chronos 思路）

⑥ 实验设计（答辩最有说服力的部分）

  • 不同定位算法对比（kNN vs WKNN vs SVR vs CNN）
  • 不同场景（机房 / 走廊 / 会议室 / 大厅）
  • 不同参考点间距（0.5m / 1m / 2m 网格）
  • 不同 AP 数量（1 个 / 2 个 / 3 个）
  • 不同天线数量与朝向
  • 有无遮挡 / 非视距（NLoS）场景

评价指标：平均定位误差（米）、定位误差 CDF 曲线、中位误差、标准差、定位准确率。

⑩ 落地建议（给大四低成本）

结论：能实现，指纹定位是性价比最高的落地形态

落地层次可行性说明
A. 毕业设计 Demo✅ 完全可行在教室 / 实验室布 2~3 个 AP，采集指纹实现定位，界面显示估计位置 + 真实位置 + 误差 CDF
B. 校园场景小应用⚠️ 半可行固定楼层指纹库可用；环境大改（桌椅挪动、人多）需重新建库
C. 商用级定位产品⚠️ 较难需解决指纹漂移、设备异构、NLoS 等；纯 CSI 商品化少，但比呼吸检测更接近成熟（有商业 WiFi 定位先例）
建议定位 本科毕业设计定位在 A 层（可演示 Demo）：选一个几十平米的房间，划 0.5m~1m 网格，采集指纹，跑通「预处理 → 特征提取 → WKNN/CNN 定位」，答辩效果直观、指标清晰。

时间节奏（2~4 个月）：环境搭建 1~2 周 → 跑通公开代码 1~2 周 → 自己采指纹调参 2~3 周 → 实验 + 写论文 4~6 周。
